# Contributing to MCD Full E-Commerce

First off, thank you for considering contributing to this project! It's people like you that make this platform such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check if there's already an issue for it. If not, open a new issue describing the problem or the proposed feature.

## Branch Naming Convention

When creating a new branch, please follow this convention:
- `feat/feature-name` for new features
- `fix/issue-description` for bug fixes
- `docs/what-changed` for documentation updates
- `refactor/what-changed` for code restructurings
- `chore/what-changed` for maintenance tasks

## Commit Messages

We use [Conventional Commits](https://www.conventionalcommits.org/). Please format your commit messages accordingly:
- `feat: add new feature`
- `fix: resolve a bug`
- `docs: update documentation`
- `refactor: restructure code without changing behavior`
- `chore: update dependencies or configuration`

## Pull Requests

1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure your code passes all existing tests and linting.
4. Update the documentation as necessary.
5. Create a pull request to `main` with a clear title and description.
